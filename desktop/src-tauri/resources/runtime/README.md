# Bundled runtime files

`deps.json` pins the downloads used by the first-run bootstrap (uv, ffmpeg,
deno) by URL and SHA-256. Everything else in this folder is generated by
`desktop/scripts/prepare-runtime.ps1` before `pnpm tauri build` and is not
committed: `uv.exe`, the engine wheel and the `pylock.*.toml` lock files.
`licenses/uv/` holds the licence texts of the bundled `uv.exe` (MIT and
Apache-2.0, from the uv repository at the pinned tag); the script copies the
app's `LICENSE` and `THIRD_PARTY_NOTICES.md` next to them.
