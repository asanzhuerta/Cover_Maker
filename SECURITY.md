# Security policy

Cover_Maker runs a local engine bound to `127.0.0.1` and protected by a
per-session token. If you find a vulnerability (for example a way for a web page
or another local user to reach the engine), please report it privately through
GitHub's **Report a vulnerability** button on the Security tab instead of
opening a public issue. We aim to reply within 14 days.

Only the latest release is supported with security fixes.
