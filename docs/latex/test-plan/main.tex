\section{Manual and measured verification}
\begin{description}
  \item[Separation quality and speed] benchmarks on an RTX~3050 Laptop (4~GB)
  and an i5-11400H (Architecture, Benchmarks); presets derived from them.
  \item[Installer, CPU path] release build run with an isolated user profile
  and a \texttt{PATH} without Python, uv or ffmpeg: first-run bootstrap,
  separation runtime (CPU build), model download and separation of a
  synthetic demo clip; re-sync after a simulated update (2026-11-03).
  \item[Release pipeline] \texttt{v0.2.0} and \texttt{v0.2.1} built, signed and
  published by \texttt{release.yml}; the updater manifest was checked.
  \item[User interface] each page exercised in a browser against the engine's
  demo mode (welcome, new job, queue, mixer, library, CC sources, settings,
  about), in English and Spanish.
  \item[Practice tools] mixer with a synthetic demo song (100 BPM, G major,
  20 cents flat) in the demo engine: the LCD showed 99 BPM, G and $-20$; pitch,
  tempo and Tune to A440 by keyboard and mouse; audio through the stretch
  worklet; offline render of six stems through it at 2.8\,\% of real time on
  one core of the i5-11400H (2026-11-11).
  \item[Catalogues] live searches on ccMixter and the Internet Archive and a
  real Internet Archive download with its credits (2026-11-04).
  \item[DAW integration] the REAPER script run against the demo engine with
  real HTTP calls and a stubbed REAPER API
  (\texttt{daw/reaper/tests/e2e\_demo.py}): four stem tracks inserted in the
  requested order, aligned with the source item; the discovery folder checked
  with \texttt{icacls} (current user only); the VST3 bundle built and its
  factory loaded (2026-11-05).
\end{description}

\section{Open items}
\begin{itemize}
  \item A clean Windows Sandbox installation and the CUDA path through the
  installer are not yet verified by the project; \texttt{desktop/scripts/sandbox-test.ps1}
  prepares the former.
  \item The app's own update from one published version to the next has not
  been exercised end to end.
  \item The VST3 plugin and the REAPER script have not yet been exercised
  inside a real host.
  \item The installer and the app are not code-signed yet (issue \#51), so
  SmartScreen warns about an unknown publisher.
  \item Listening tests are informal; the M1 report lists the blind test as
  pending.
  \item The practice tools assume 4/4 for bars; beat tracking on real
  recordings with tempo changes has only been checked by ear.
\end{itemize}
