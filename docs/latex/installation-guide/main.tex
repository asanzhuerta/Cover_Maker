\CM{} needs the Microsoft Edge WebView2 runtime, which is part of Windows 10
(since 2021) and Windows 11; the installer downloads it when it is missing.
For the GPU path, install a current NVIDIA driver; the CUDA libraries come with
the app.

\chapter{Installation}
\begin{enumerate}
  \item Download \texttt{Cover\_Maker\_<version>\_x64-setup.exe} from the
  project's GitHub Releases page.
  \item Run it. The installer works per user and does not ask for administrator
  rights. It installs into
  \texttt{\%LOCALAPPDATA\%\textbackslash Cover\_Maker}, the same folder that
  holds the runtime and your data, and adds a Start-menu entry.
  \item Windows SmartScreen may warn that the publisher is unknown, because
  the installer is not code-signed yet. Choose \emph{More info} and \emph{Run
  anyway} only if you downloaded it from the official Releases page.
\end{enumerate}

For an unattended install, run the installer with \texttt{/S}.

\chapter{First run}
The first start installs the local engine. A \emph{Setting up Cover\_Maker}
screen lists the steps and shows their progress:
\begin{enumerate}
  \item \textbf{Python 3.12}: a private copy, not added to \texttt{PATH}.
  \item \textbf{Engine environment}: a virtual environment.
  \item \textbf{Engine and core libraries}, installed from lock files that pin
  every package by version and hash.
  \item \textbf{ffmpeg} (LGPL build, for decoding and MP3) and \textbf{deno}
  (used by yt-dlp for some video sites), checked against pinned SHA-256 hashes.
\end{enumerate}
This takes one to a few minutes, depending on the connection. When it is done
the usual welcome screen appears.

The \textbf{separation runtime} (PyTorch and audio-separator) is installed
next, in the background; the sidebar shows \emph{Installing the separation
runtime} with the chosen build. If an NVIDIA GPU with compute capability 7.5
or higher (Turing, RTX~20 series or newer) is found, the CUDA build is used
(about 4~GB of downloads), otherwise the CPU build (under 1~GB). You can go
through the welcome screen meanwhile. Installing models and separating need
this step: until it finishes, the \emph{Models} and \emph{New job} pages show a
notice and the \emph{Install} buttons are disabled. When it is done, the box at
the bottom left of the sidebar shows \emph{Separation runtime installed}.

Everything is stored in
\texttt{\%LOCALAPPDATA\%\textbackslash Cover\_Maker\textbackslash runtime}.
Models are not part of the setup: you choose and download them on the
\emph{Models} page after reading their licences.

\chapter{Updates and removal}
\section{App updates}
\emph{Settings $\rightarrow$ Updates $\rightarrow$ Check for updates} asks
GitHub Releases for a newer version. Updates are signed; the app verifies the
signature before it installs one, then restarts. After an update the setup
screen appears briefly while the engine is re-synced with the new lock files;
the separation runtime is kept and updated in place.

\section{yt-dlp updates}
Video sites change often. \emph{Check for yt-dlp update} compares the installed
yt-dlp with the newest release on PyPI and offers \emph{Update}; the engine
restarts afterwards. The next app update sets yt-dlp back to the version tested
with that release.

\section{Removal}
Uninstall from \emph{Settings $\rightarrow$ Apps} or the Start menu. The
uninstaller always removes the app and its runtime folder. Your library,
models, database and logs in
\texttt{\%LOCALAPPDATA\%\textbackslash Cover\_Maker} are removed only if you
tick \emph{Delete the application data}. Exported stems in your own folders are
never touched.

\chapter{Troubleshooting}
\begin{description}
  \item[Setup could not finish.] The error is shown on the setup screen. Check
  the internet connection, proxy or firewall, then choose \emph{Retry}:
  completed downloads are kept in the cache, so the retry continues where it
  stopped. The setup needs access to \texttt{github.com},
  \texttt{pypi.org}, \texttt{files.pythonhosted.org} and
  \texttt{download.pytorch.org}.
  \item[Antivirus blocks the setup.] Some antivirus products quarantine
  \texttt{uv.exe} or files in the new environment. Allow the folder
  \texttt{\%LOCALAPPDATA\%\textbackslash Cover\_Maker} and retry.
  \item[Separation runtime not installed.] The sidebar shows the error and a
  \emph{Retry} button. The CUDA build is a large download; on slow or metered
  connections you can force the smaller CPU build by setting the user
  environment variable \texttt{COVER\_MAKER\_TORCH=cpu} and restarting the app.
  \item[The GPU is not used.] Update the NVIDIA driver and check that
  \texttt{nvidia-smi} works in a terminal. If the CPU build was installed
  first, close the app, delete
  \texttt{\%LOCALAPPDATA\%\textbackslash Cover\_Maker\textbackslash runtime} and
  start the app again.
  \item[Start over.] Close the app and delete the \texttt{runtime} folder; the
  next start runs the setup again. Your library and models are not affected.
  \item[Video links stop working.] Use \emph{Check for yt-dlp update}.
\end{description}
