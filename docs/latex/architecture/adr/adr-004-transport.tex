\section{ADR-004: Local HTTP and WebSocket transport}
\textbf{Status:} accepted (M2). \textbf{Context:} the UI needs request/response
calls, streamed progress events and, later, ranged audio downloads from the
engine. \textbf{Decision:} the engine exposes FastAPI over HTTP plus a
WebSocket for events on 127.0.0.1 and a random port. Tauri IPC is used only for
operating-system features and to hand the UI the port and token.
\textbf{Security:} a 32-byte token generated by the shell is passed through the
environment, never on the command line. Every HTTP request must carry
\texttt{Authorization: Bearer}, the exact \texttt{Host} the engine bound to (which
defeats DNS rebinding) and, if present, an allowed \texttt{Origin}. WebSocket
clients authenticate with their first message because browsers cannot set
headers on WebSockets; a wrong token closes the socket with code 4401.
\textbf{Consequences:} OpenAPI can generate TypeScript types; the API is
testable without the shell; no business logic is written in Rust.
